- C51.5: Fails on two points: (1) L28, L194, and L216 conflate Linux OverlayFS `upperdir` whiteouts (which `https://docs.kernel.org/filesystems/overlayfs.html#whiteouts-and-opaque-directories` defines as a `0/0` character device or zero-size file with `trusted.overlay.whiteout` xattr, and `https://docs.docker.com/engine/storage/drivers/overlayfs-driver/#deleting-files-and-directories` refers to simply as a "whiteout file" in `upperdir`) with `.wh.<basename>` entries, which `https://github.com/opencontainers/image-spec/blob/main/layer.md#whiteouts` defines as regular files inside OCI layer changeset tar archives (`"A whiteout filename consists of the prefix .wh. plus the basename of the path to be deleted. ... Note that regardless of the path being deleted, the whiteout file is a regular file in the archive."`); (2) L28 says BuildKit only packages `tar`/`tar+gzip`/`tar+zstd` on push/export, whereas `https://github.com/moby/buildkit/blob/master/README.md` documents `compression=<uncompressed|gzip|estargz|zstd>` and `https://docs.docker.com/build/builders/drivers/` shows local tarball loading (`sending tarball`) for the `docker` driver too.
