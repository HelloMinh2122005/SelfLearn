  - **(3) Revoking bootstrap token after bootstrap**: Neither `fluxcd.io/flux/installation/bootstrap/gitlab/` nor `docs.gitlab.com/user/project/deploy_keys/` instructs revoking `GITLAB_TOKEN` immediately after bootstrap. Under GitLab SSH deploy key mode, `flux-system` Secret stores the SSH private key (not the PAT) and `docs.gitlab.com/user/project/deploy_keys/` confirms `"Deploy keys are not rejected when the deploy key owner is removed from the group or project. The deploy key continues to provide access until it is revoked"` (recommending a service account). By contrast, under `--token-auth` the PAT is stored in `flux-system`, and on GitHub `fluxcd.io/flux/installation/bootstrap/github/` warns `"when the PAT is removed or when it expires, the GitHub deploy key will stop working."` Thus README bullet 5 (`token quyền cao chỉ dùng lúc bootstrap`) holds for GitLab SSH deploy key / `--deploy-token-auth`, while lesson L59/L124/L190/L223 (`thu hồi ngay`) is an inference not explicitly stated in GitLab/Flux docs (and false for GitHub or `--token-auth`).
